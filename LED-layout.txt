LED CLOCK LAYOUT

Here is how the LEDs are laid out:

      ####    ####       ####     ####       ####     ####  
     #    #  #    #     #    #   #    #     #    #   #    #   
     #    #  #    #  #  #    #   #    #  #  #    #   #    #   AM
      ####    ####       ####     ####       ####     ####    PM
     #    #  #    #  #  #    #   #    #  #  #    #   #    #   24H
     #    #  #    #     #    #   #    #     #    #   #    #   Date
      ####    ####       ####     ####       ####     ####   

Digit 0 is on the left, and Digit 5 is the one on the right.


Each digit is laid out like this:

    0000
   1    5
   1    5
    6666 
   2    4
   2    4
    3333  7

The Most Significant Bit (MSB) is on the left.  So if you set
one of the digits to 0x80, you'll get just the decimal point.
If you set it to 0x08, you'll get only the center horizonal bar.

To show a '1', you need to turn on bits 2 and 5; in binary, you
need: 00100100 (remember we start counting at zero, so the rightmost
bit is bit zero).  In Hex, that gives 0x24.


'extras' is used for the colons and the AM/PM/24H/Date indicators.

The bit values are:

    Date indicator:  0x01
    PM indicator:    0x02
    AM indicator:    0x04
    24H indicator:   0x08

    upper-left dot:  0x10
    upper-right dot: 0x20
    lower-left dot:  0x40
    lower-right dot: 0x80

So, for example, setting digit 7 to '0xF4' would turn on all four dots
and illuminate the 'PM' indicator.
